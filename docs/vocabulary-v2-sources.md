## 転記・出題ルール

- 単語・熟語・定型表現・過去形・固有名詞を省略せず収録。
- 折り返しと句読点の体裁を整え、意味や英語の綴りは印刷欄に合わせる。
- `～` は英語の可変部分では `~` として表示。入力テストではこの記号は省略できる。
- `journey` と `trip` は両方「旅行」。入力テストではどちらも正解とし、4択では同一の意味を重ねない。
- 4択では同じ英語の別の意味も誤答候補から除外する。
- 地名・意味は教材の表記を学習対象として収録しており、現在の公式地名についての主張ではない。
- 発音は既存どおり端末の音声合成を使用。`read` の過去形など、綴りだけで発音を特定できない語の読みは音声エンジンに依存する。

## v2.1 の学習記録と写真別範囲

- 状態は `lastCorrect` により「覚えた」「苦手」に分類し、有効な回答記録がなければ「未学習」。現在の200個のIDだけを集計し、別のIDは数えない。
- 正解後も誤答の累積履歴は保存するが、現在の苦手判定には累積回数を使わない。3区分は相互排他的で、合計は200。
- 回答順序を記録していない初期v2データでは、誤答履歴があれば苦手とする保守的な移行を行う。次の回答で状態が確定する。
- 入力テストの同じ問題を再入力しても、最初の1回だけを得点と学習記録に反映する。正解を見た直後の練習を独立した正答として扱わない。
- `source` ごとに単語表15枚の範囲を生成し、`row` の順に出題する。STEP 2/3 の9枚は重複する確認テストなので、別の単語表として増やさない。
- 表示上の「写真1〜15」は上の表の STEP 1 写真を順に数えた番号。選択欄には英語の開始・終了と項目数、補足にはファイル名と教材ページを表示する。

## 検証

`pnpm test` は項目数・範囲ごとの件数・IDの一意性・4択の選択肢・入力判定を検証する。
`pnpm build` は公開用ファイルを生成する。写真との意味対応は目視で確認したものであり、自動テストは転記内容の意味的正しさを保証するものではない。
