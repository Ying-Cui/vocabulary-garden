## 転記・出題ルール

- 単語・熟語・定型表現・過去形・固有名詞を省略せず収録。
- 折り返しと句読点の体裁を整え、意味や英語の綴りは印刷欄に合わせる。
- `～` は英語の可変部分では `~` として表示。入力テストではこの記号は省略できる。
- `journey` と `trip` は両方「旅行」。入力テストではどちらも正解とし、4択では同一の意味を重ねない。
- 4択では同じ英語の別の意味も誤答候補から除外する。
- 地名・意味は教材の表記を学習対象として収録しており、現在の公式地名についての主張ではない。
- 発音は既存どおり端末の音声合成を使用。`read` の過去形など、綴りだけで発音を特定できない語の読みは音声エンジンに依存する。

## 保存と更新

旧版の `kotoba-garden-v1` は変更・削除しない。v2 は `kotoba-garden-v2-p93-115` に保存するため、旧版の数値IDの記録が別の新単語に割り当たらない。
PWA キャッシュ名も更新し、新しい単語データを含むビルドを取得できるようにする。

## 検証

`pnpm test` は項目数・範囲ごとの件数・IDの一意性・4択の選択肢・入力判定を検証する。
`pnpm build` は公開用ファイルを生成する。写真との意味対応は目視で確認したものであり、自動テストは転記内容の意味的正しさを保証するものではない。
