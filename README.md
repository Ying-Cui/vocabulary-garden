# ことばの庭 v2

紙の英単語リストから作成した、スマホ対応の学習Webアプリです。
v2 は写真で提供された p.93–115 の5範囲、計200項目（単語・熟語・定型表現）に更新しています。
現行版の画面・学習機能を引き継ぎ、旧版の学習記録を残して新しい記録を別に保存します。

## v2.3 の学習機能

1. **今日の自動学習**：全200語から、期限が来た復習を古い順に優先し、残りを未学習語で補って最大20語を選びます。期限前の単語は自動学習には混ぜません。
2. **定着判定**：復習期限を迎えた別々の3日に、ヒントなしの英語入力で正解すると「定着」。同日の反復、期限前の回答、4択、カード、ヒント付き回答は定着回数に加えません。1・3・7・14・30日の間隔で復習し、不正解なら翌日に戻します。
3. **少し後の再テスト**：間違えた語は、別の3語以上を挟んで同じ学習内に再出題します。範囲内の復習語を追加して間隔を作り、1語につき再出題は1回まで。範囲が小さく3語を挟めない場合は翌日に回します。
4. **段階学習**：カード → 日本語から英語の4択 → 頭文字ヒント付き入力 → ヒントなし入力。正解すると次の学習で段階が進み、不正解なら1段階戻ります。
5. **写真を混ぜた実力テスト**：ホームの折りたたみ欄で写真を2枚以上選び、最大20語をヒントなし入力で確認。選んだ各写真から出題されるように混ぜます。

「未学習・練習中・要復習・定着」は相互排他的で、常に合計200項目です。定着済みでも期限が来れば要復習に戻ります。ここでいう定着はアプリの運用上の判定であり、長期記憶を保証するものではありません。判定・出題の詳細は [学習ルール](docs/learning-policy.md) を参照してください。

既存の機能も利用できます。

- カード、両方向の4択クイズ（英語 → 日本語 / 日本語 → 英語）、入力テスト。
- ランダム20語、写真15枚ごとの15語・10語、要復習だけの入力。
- 同じ問題の「もう一度入力する」練習。入力欄を空にして答えを隠し、得点・学習記録に重複加算しません。
- 範囲・クイズ方向・混合テストの選択を端末に保存。オフラインでも動作します。

以前の学習記録は回数を保持して引き継ぎ、移行前データを端末内にバックアップします。過去の正解回数を、別日に思い出せた証拠へ変換することはしません。旧記録のある語は最初は要復習と表示します。

## 使い方

1. このフォルダで `npm install` を実行します。
2. `npm run dev` を実行します。
3. 表示されたURLをスマートフォンまたはPCのブラウザで開きます。

## iPhoneへインストール

1. このアプリをHTTPS対応のWebサーバーへ公開します。
2. iPhoneのSafariで公開URLを一度開きます。
3. Safari下部の共有ボタン（四角から上向き矢印）を押します。
4. 「ホーム画面に追加」→右上の「追加」を押します。
5. ホーム画面の「ことばの庭」アイコンから起動します。

初回だけ通信が必要です。最初に一度開けば、単語データ・画面・学習記録を端末に保存し、以後はオフラインでも使用できます。新しい版へ更新するときは、通信できる状態でアプリを開いてください。

## PWA対応

- iPhone用ホーム画面アイコン（180px）
- PWA用アイコン（192px・512px・マスカブル）
- ホーム画面から独立したアプリ画面として起動
- Service Workerによるオフラインキャッシュ
- 画面上部・ノッチ周辺を含むiPhone表示への対応

## 学習機能

- 毎回ランダムな20語で学習
- 英単語カード（発音・意味確認）
- 4択クイズ
- 日本語から英語を答える入力テスト
- 間違えた単語を集めた苦手復習
- 単語一覧と検索
- 学習記録の端末内保存

画像内のSTEP 1ページを正本として転記しています。同じ `take` でも意味が異なる2項目は両方収録しています。
転記元の写真名・行番号と出題ルールは [データ出典](docs/vocabulary-v2-sources.md) を参照してください。
