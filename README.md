# ことばの庭 v2

紙の英単語リストから作成した、スマホ対応の学習Webアプリです。
v2 は写真で提供された p.93–115 の5範囲、計200項目（単語・熟語・定型表現）に更新しています。
現行版の画面・学習機能を引き継ぎ、旧版の学習記録を残して新しい記録を別に保存します。

## v2.1 の追加・修正

v2.2 では、クイズ画面の「クイズの向き」で「英語 → 日本語」「日本語 → 英語」を選べます。写真別・ランダム20語に共通で、選択を端末に保存します。方向を切り替えると1問目から新しく出題し、回答済みの学習記録は残します。
日本語 → 英語では4つの英語から選び、正解の発音は回答後に聞けます。同じ意味の英語や、別の意味で収録された同じ綴りを同一問題の選択肢に重ねません。

- 入力テストの回答後に「もう一度入力する」で同じ単語を練習できます。入力欄を空にし、答えを隠して再入力します。練習の再入力は初回の得点・学習記録に重複加算しません。
- 学習状況は「覚えた」「苦手」「未学習」のいずれか1つに分類し、合計が常に全200項目になります。次の学習で正解した語は苦手から外れ、不正解なら再び苦手になります。「覚えた」は直近の回答・自己評価が正解だったことを表し、長期定着を保証する指標ではありません。
- 全体からランダム20語のほか、単語表の写真15枚ごとに15語・10語を選べます。写真別は掲載順に学習し、選択した範囲はカード・クイズ・入力テスト・単語一覧・苦手復習に共通です。
- 写真別の再学習は同じ範囲を維持し、苦手復習の再学習は未解消の苦手だけを出題します。
- 学ぶ範囲は端末に保存します。端末保存に失敗した場合は画面にお知らせします。

過去のv2記録に回答順序が残っていない場合、誤答がある語は一旦「苦手」、正答のみの語は「覚えた」と表示します。次の学習から直近の回答で更新します。過去の正誤回数は消しません。

## 使い方

1. このフォルダで `npm install` を実行します。
2. `npm run dev` を実行します。
3. 表示されたURLをスマートフォンまたはPCのブラウザで開きます。

## iPhoneへインストール

1. このアプリをHTTPS対応のWebサーバーへ公開します。
2. iPhoneのSafariで公開URLを一度開きます。
3. Safari下部の共有ボタン（四角から上向き矢印）を押します。
4. 「ホーム画面に追加」→右上の「追加」を押します。
5. ホーム画面の「ことばの庭」アイコンから起動します。

初回だけ通信が必要です。最初に一度開けば、単語データ・画面・学習記録を端末に保存し、以後はオフラインでも使用できます。新しい版へ更新するときは、通信できる状態でアプリを開いてください。

## PWA対応

- iPhone用ホーム画面アイコン（180px）
- PWA用アイコン（192px・512px・マスカブル）
- ホーム画面から独立したアプリ画面として起動
- Service Workerによるオフラインキャッシュ
- 画面上部・ノッチ周辺を含むiPhone表示への対応

## 学習機能

- 毎回ランダムな20語で学習
- 英単語カード（発音・意味確認）
- 4択クイズ
- 日本語から英語を答える入力テスト
- 間違えた単語を集めた苦手復習
- 単語一覧と検索
- 学習記録の端末内保存

画像内のSTEP 1ページを正本として転記しています。同じ `take` でも意味が異なる2項目は両方収録しています。
転記元の写真名・行番号と出題ルールは [データ出典](docs/vocabulary-v2-sources.md) を参照してください。
